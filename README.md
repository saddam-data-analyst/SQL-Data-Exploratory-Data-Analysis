## Overview
This project demonstrates professional SQL analytics on a data warehouse, featuring:
- Comprehensive Exploratory Data Analysis (EDA)
- Business metric calculations (KPIs, revenue, customer segmentation)
- Advanced analytics (window functions, time-series, part-to-whole analysis)
- Ready-to-use views for Power BI/Tableau integration

## Key Features
🔍 **Exploratory Analysis** - Database schema exploration and data profiling  
📊 **Business Metrics** - 20+ key performance indicators calculated  
⏳ **Time-Series Analysis** - Monthly/Yearly trends with moving averages  
👥 **Customer Segmentation** - VIP/Regular/New classification with RFM metrics  
📈 **Product Performance** - High/Mid/Low performer categorization  
🎯 **Advanced SQL** - Window functions, CTEs, complex joins
